# CSS Learning Assignments

Practice assignments from Osama Elzero's CSS course (Elzero Web School), built while working through the course material.

Course playlist: https://www.youtube.com/watch?v=X1ulCwyhCVM&list=PLDoPjvoNmBAzjsz06gkzlSrlev53MGIKe

## Structure

Assignments are added incrementally as I progress through the course. Each `CSS-Assignment-N` folder contains:
- `index.html` - the assignment markup
- `CSS/` - stylesheets
- `imgs/` (where used) - images required by the assignment
- `screenshots/` - my solution, showing the final result

## Purpose

Hands-on practice to reinforce CSS fundamentals - selectors, box model, flexbox, layout, responsive design.
Shared publicly as reference for anyone working through the same course.
Credit for the course material goes to Osama Elzero / Elzero Web School.
